Baixe **SUCURI-Local-Windows.zip**, extraia todo o conteúdo em uma pasta Windows local (C: ou D:, fora do WSL) e abra **SUCURI Local.exe**.

1. Escolha uma pasta para os dados (por exemplo `D:\SUCURI`).
2. Clique em **Iniciar serviço**, depois em **Copiar código** e **Abrir site**.
3. Cole o código no site, clique em **Conectar computador** e permita o acesso à rede local.

Mantenha o aplicativo aberto durante os downloads e processamentos. Se o navegador bloquear a conexão, use **Abrir versão local** no aplicativo.

Esta versão Windows x64 é portátil e ainda não possui assinatura digital. Não requer instalação de Python. Bases e resultados ficam na pasta escolhida, fora do aplicativo. O código expira em 10 minutos e só pode ser usado uma vez; use **Novo código** para conectar outra aba.

O aplicativo gera arquivos de entrada para fluxo de potência; não executa uma simulação elétrica. Consulte o relatório de cada rede antes de usar os resultados.
